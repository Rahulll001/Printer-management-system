🖨️ Printer Management System

A simple Python program demonstrating Stack and Queue using Linked Lists in a real-world printer management system.

Features

- Add print requests using Queue (FIFO)
- Process print requests
- Store printed documents using Stack (LIFO)
- Display print queue and printed history
- Menu-driven interface

Technologies

- Language: Python
- Concepts: Stack, Queue, Linked List

Purpose

This project demonstrates the practical implementation of Stack and Queue operations using Linked Lists.
